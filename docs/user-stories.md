# User Stories
### Acceptance Criteria 1: User Login and Registration

- Users can register for a new account by entering the required information.
- Users can log in using valid credentials.
- The system displays an error message when invalid login details are entered.
- Users can access the car rental features after successfully logging in.

### Acceptance Criteria 2: Car Booking and Rental

- Users can view the list of available cars with their details and rental prices.
- Users can select an available car and enter the required rental details.
- The system confirms the booking when all required information is valid.
- The system prevents users from booking a car that is unavailable for the selected rental period.

### Acceptance Criteria 3: Administrator Car Management

- The administrator can log in using valid administrator credentials.
- The administrator can add new cars with details such as car name, model, rental price, and availability.
- The administrator can update the details of existing cars.
- The administrator can remove cars from the system when they are no longer available for rental.
- The system displays a confirmation message when car information is successfully added, updated, or deleted.
